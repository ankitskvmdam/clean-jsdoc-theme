# @clean-jsdoc-theme/ui

Internal: Astro components for clean-jsdoc-theme v5.

The component library. Pure Astro components — no JSDoc knowledge, no build logic. Signature renderers, parameter tables, type badges, deprecation cards, version pills, callouts, kind-specific page layouts (class page vs. function page vs. namespace page), and all the design system primitives (buttons, kbd, code block frames).
This is where your style investment lives and where you differentiate from every other doc theme. Designed to be consumable outside Astro-specific context — someone using core + ui in a Next.js/Fumadocs setup should get the same components.
