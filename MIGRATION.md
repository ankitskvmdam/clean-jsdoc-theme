# Migration Guide

## Staying on v4

Pin the v4 major version in your `package.json`:

```json
{
  "devDependencies": {
    "clean-jsdoc-theme": "^4"
  }
}
```

v4 will continue to receive security patches for 12 months after v5 ships.
