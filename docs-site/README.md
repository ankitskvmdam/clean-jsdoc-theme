# API reference demo

This is a **live API reference**, generated by
[`clean-jsdoc-theme`](https://github.com/ankitskvmdam/clean-jsdoc-theme) — the
exact output you get from pointing JSDoc at the theme. Every page here was built
from one small, fully-commented sample module in
[`src/`](https://github.com/ankitskvmdam/clean-jsdoc-theme/blob/master/docs-site/src/index.js);
nothing was written by hand.

> [!TIP]
> Press `Ctrl K` to fuzzy-search every symbol, or browse from the sidebar.
> Toggle light/dark in the header, and use the **copy page** button at the top
> of any page to hand its Markdown to Claude, ChatGPT, or Perplexity.

## Start exploring

- **[sample-api](/module/sample-api)** — the module page. It opens with an
  `[!INFO]` callout, a `<steps>` walkthrough, and install `<tabs>` — all authored
  inline in the `@module` doc comment.
- **[Cache](/module/sample-api/cache)** — a documented class: constructor,
  properties, and methods, each rendered as its own section with parameters,
  return types, and `@example` blocks.
- **[createCache](/module/sample-api#createcache)** — a factory function, showing
  `{@link}` cross-references resolved to real anchors.

## What it shows off

- Server-rendered pages with lazy-hydrated islands — fast, and usable with no JS.
- A companion `.md` beside every page (what the copy-page button serves to LLMs).
- `Source: file:line` links into a read-only Monaco viewer on the source pages.
- The theme's authoring components — callouts, steps, and tabs — written straight
  into JSDoc comments, not just prose.

New here? The **clean-jsdoc-theme Guide** link in the sidebar opens the full
documentation — installation, configuration, and theming.
