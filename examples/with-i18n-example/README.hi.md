# Widget Kit — स्थानीयकृत दस्तावेज़ का उदाहरण

**`clean-jsdoc-theme` के बहु-भाषा समर्थन** के लिए एक न्यूनतम उदाहरण, जो तीन
भाषाओं में बनाया गया है: अंग्रेज़ी (`en`, डिफ़ॉल्ट), जापानी (`ja`) और
हिन्दी (`hi`)।

API संदर्भ (`Widget` क्लास + मॉड्यूल अवलोकन) को
`clean-jsdoc-theme-artifacts/locales/` में रखी गई कैटलॉग के ज़रिए प्रत्येक लोकेल
के लिए अनुवादित किया जाता है, और UI (खोज, नेविगेशन, सेटिंग्स, विषय-सूची) भी
स्थानीयकृत है। यह होम पेज `README.<locale>.md` के माध्यम से प्रत्येक लोकेल के लिए
स्थानीयकृत होता है। भाषा बदलने के लिए हेडर में **Languages** नियंत्रण का उपयोग करें
(डेस्कटॉप पर खोज आइकन के बाद; मोबाइल पर मेन्यू बटन से पहले बार में)।

## आज़माकर देखें

```sh
pnpm install
pnpm --filter example-with-i18n run docs   # build the theme, then every locale
pnpm --filter example-with-i18n run serve  # serve ./dist
```

डिफ़ॉल्ट लोकेल रूट (`/`) पर रेंडर होता है; बाकी `/ja` और `/hi` के अंतर्गत।

## स्थानीयकरण की कार्यप्रणाली

```sh
clean-jsdoc i18n extract   # API + chrome कुंजियों के विरुद्ध प्रति-लोकेल कैटलॉग सिंक करें
clean-jsdoc i18n prompt    # (वैकल्पिक) अनट्रांसलेटेड कुंजियों के लिए LLM प्रॉम्प्ट दें
clean-jsdoc i18n validate  # कैटलॉग की प्रीफ़्लाइट जाँच करें
clean-jsdoc build          # स्टैम्प करें + प्रति लोकेल एक साइट रेंडर करें
```

> नोट: होम पेज स्थानीयकृत है — `aadesh build` साथ रखी गई
> `README.<locale>.md` (यहाँ `README.ja.md` / `README.hi.md`) को उठाकर उसे उस
> लोकेल के होम के रूप में रेंडर करता है, और वैरिएंट न होने पर इस `README.md` पर
> वापस आ जाता है। बची हुई प्रोज़-ट्रैक कमी होम नहीं, बल्कि बहु-पृष्ठ
> दस्तावेज़/ट्यूटोरियल हैं।
