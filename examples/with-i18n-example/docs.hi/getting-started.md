# शुरुआत करें

ये गद्य पृष्ठ `opts.docs` (`docs/` डायरेक्टरी) में रहते हैं और साथ रखी
`docs.<locale>/` ओवरले के ज़रिए प्रत्येक लोकेल के लिए स्थानीयकृत होते हैं — अनुवादित
पृष्ठ प्राथमिकता पाता है, और अनुवाद न होने पर यह डिफ़ॉल्ट दिखाया जाता है।

## इंस्टॉल करें

```sh
pnpm add -D clean-jsdoc-theme @clean-jsdoc-theme/aadesh
```

## अपने लोकेल घोषित करें

अपनी `jsdoc.json` में `opts.locales` और `opts.defaultLocale` जोड़ें, फिर बिल्ड चलाएँ:

```sh
clean-jsdoc i18n extract   # कैटलॉग सिंक करें
clean-jsdoc build     # प्रति लोकेल एक साइट रेंडर करें
```

डिफ़ॉल्ट लोकेल रूट पर रेंडर होता है; बाकी हर लोकेल `/<locale>` के अंतर्गत।
